We were introduced to the 5S methodology, a Japanese workplace organization method widely used to improve efficiency and maintain an organized working environment.

Seiri (Sort)

Remove unnecessary items and keep only what is required.

Seiton (Set in Order)

Arrange necessary items so that they are easy to find and use.

Seiso (Shine)

Keep the workplace clean and identify sources of problems.

Seiketsu (Standardize)

Create consistent practices and standards.

Shitsuke (Sustain)

Develop discipline to continuously follow the established practices.

What made this session particularly useful was the practical application of the method. We were able to understand how 5S can be implemented rather than learning it only as a theoretical concept.

Week 06: Laser Cutting

Introduction to Laser Cutting

Laser cutting is a digital manufacturing process that uses a focused laser beam to cut or engrave materials according to a digital design. The laser produces a concentrated amount of heat on a specific path, causing the material to melt, burn, or vaporize.

Laser cutting is commonly used in prototyping, product design, model making, signage, packaging, and manufacturing because it provides accurate, precise, and repeatable results.

Common materials used for laser cutting include acrylic, plywood, MDF, cardboard, paper, leather, and certain plastics and metals, depending on the type and power of the laser cutter.

Core Concepts of Laser Cutting

1. Laser Beam

A concentrated beam of light that produces high energy at a specific point, generating heat to cut or engrave.

2. Power

Higher power → deeper/stronger cutting. Lower power → lighter cutting or engraving. Depends on material and thickness.

3. Speed

Lower speed → more energy delivered. Higher speed → less energy delivered. Must be balanced with power.

4. Focus

Correct focusing produces a concentrated laser spot and improves cut quality and accuracy.

5. Cutting vs Engraving

Cutting separates the material, while engraving removes or marks only the surface without completely cutting through.

6. Vector Cutting

Generally follows lines, curves, and outlines defined in a vector-based design such as DXF.

7. Kerf

The small amount of material removed by the laser beam (the actual cut may be slightly wider than the design line).

8. Air Assist

Directs air towards the cutting area to remove smoke/debris and reduce burning.

Introduction to RDWorks V8

RDWorks V8 is software used to prepare designs for laser cutting and engraving machines, particularly machines using Ruida-compatible controllers.

  • Import DXF and other design files
  • Edit, arrange, resize, and position designs
  • Assign different layers/colours
  • Set cutting/engraving parameters (speed and power)
  • Preview cutting path and send to machine

Step-by-Step Process Using RDWorks V8

1. Select & Convert Image to DXF

Select a picture with a clear and recognizable shape. Convert it into a DXF (Drawing Exchange Format) file using a converter tool.

2. Import & Check Design

Open RDWorks, go to File → Import, and open the DXF file. Inspect it carefully to ensure the outline is correct and there are no unwanted or duplicate lines.

3. Adjust Size & Position

Set required dimensions (e.g., 50x50 mm) maintaining aspect ratio. Position the design to fit within the available material in the working area.

4. Assign Layers & Parameters

RDWorks uses colours to define operations (e.g., Red for Cutting, Blue for Engraving). Set Layer Parameters like Speed, Min Power, and Max Power based on material type and thickness.

5. Set Cutting Order & Preview

Ensure internal holes/details are cut before the outer boundary. Use the Preview option to verify the path, order, and size before sending to the machine.

6. Machine Setup & Cutting

Place flat material, set focus and origin, use the Frame function to verify bounds, send the design, and start cutting while observing through the window.

Conclusion

Laser cutting is an accurate and efficient digital manufacturing technique that converts a digital design into a physical product using a focused laser beam. Through this process, the selected image was converted into a DXF file, imported into RDWorks V8, and prepared for laser cutting by adjusting its size, position, layer, speed, and power settings. The design was then previewed, positioned on the material, and processed using the laser cutting machine. This activity provided practical knowledge of laser-cutting concepts, RDWorks V8, design preparation, machine settings, and the overall digital-to-physical manufacturing process.

3D PRINTING MODEL – BAMBU STUDIO

Introduction to Bambu Studio

Bambu Studio is a 3D-printing slicer software developed for Bambu Lab printers. It converts a 3D model into instructions that the printer can follow, including layer-by-layer toolpaths, temperatures, speeds, infill, supports and other printing parameters.

It supports workflows such as slicing, auto-arranging, auto-orienting, support generation, multi-material printing, painting and G-code preview. It is available for Windows, macOS and Linux.

Bambu Studio converts a 3D CAD/model file into printable instructions for a 3D printer.

Bambu Studio Process
3D Model → Import → Select Printer → Select Filament → Orient → Scale → Add Supports → Set Print Parameters → Slice → Preview → Export/Send to Printer → Print
1. Create or obtain the 3D model: Create the model in software such as Fusion 360, Blender or Tinkercad, or download an existing STL/3MF model.
2. Import into Bambu Studio: Open Bambu Studio and import the model. Common formats include: STL, 3MF, OBJ, STEP.
3. Select printer & filament: Select the printer you are going to use (e.g., Bambu Lab H2S) and choose the material/filament profile (e.g., PLA Basic).
4. Position the model: Use Move, Rotate, Scale, Lay on Face, Auto Orient, and Arrange to position the model correctly on the build plate.
5. Add supports: Supports are added below areas that cannot be printed properly. Bambu Studio provides Normal, Tree/Hybrid, and customized supports.
6. Set print parameters: Important parameters include Layer height, Wall loops, Infill percentage/pattern, Print speed, Nozzle/Bed temperature, Cooling, and Bed adhesion.
7. Slice the model: Click "Slice plate". The slicer divides the model into individual layers and calculates the toolpath.
8. Preview: Go to Preview and move the layer slider to inspect the print layer by layer. Check supports, walls, infill, first layer, travel movements, and missing sections.
9. Print/Export: Print plate (send directly to the printer) or export the sliced file/project.

Advantages

  • Easy-to-use graphical interface
  • Automatic arrangement on build plate
  • Automatic orientation for suitable positioning
  • Automatic and manual support generation
  • Preview actual layer-by-layer toolpath
  • Multi-material capabilities and painting
  • Remote monitoring with compatible printers
  • Advanced control at global, object, and part levels

Limitations

  • Primarily designed around Bambu Lab ecosystem
  • Advanced functions depend on printer hardware
  • Incorrect slicing settings lead to failed prints
  • Supports increase print time and material
  • Highly detailed models require long processing time
  • Different materials need different thermal settings
  • Preview does not guarantee a successful physical print

Temperature strongly depends on the filament manufacturer, material, and printer profile. These values are starting ranges. Do not manually change the temperature unless necessary; the Bambu profile provides appropriate starting parameters.

Preparing The Unicorn Model

Printer: Bambu Lab H2S

Nozzle: 0.4 mm

Filament: PLA Basic

Layer height: 0.20 mm

Profile: 0.20 mm Standard – BBL H2S

Model filament: 9.99 m / 30.28 g

Support filament: 1.61 m / 4.87 g

Total: 11.60 m / 35.16 g (~1 h 34 min)

1. Open & Setup

Open Bambu Studio on Mac, go to the Prepare tab, select the Bambu Lab H2S printer (0.4mm nozzle), and select PLA Basic filament.

2. Import & Orient

Import the Unicorn STL file. Keep the rectangular base completely flat on the build plate to provide a stable foundation. Avoid rotating the entire model onto its side. Check the scale to ensure it fits the H2S build volume, and center it on the plate.

3. Enable Supports

The unicorn has overhanging areas like the head, horn, mane, tail, raised legs, and curved body. Go to Process → Support → Enable Support. Use Tree/Hybrid support type, which is excellent for organic models.

Note: Be careful with the "On build plate only" option. For this model, some overhangs (like the mane) may be better supported from the model itself rather than just the plate.

4. Slice & Preview

Click Slice plate. It is VERY IMPORTANT to move the layer slider to inspect the print layer by layer. Look for: base printing correctly, connected legs, solid body structure, horn and tail integrity, adequate supports under overhangs, and ensure there are no floating sections.
